# 认知偏误日志

记录用户反复出现的思维偏误，作为比维度评分更底层的根因分析数据。

## 偏误分类标准

| 偏误类型 | 描述 | 典型触发词 |
|----------|------|-----------|
| 计划谬误 | 高估自己完成任务的效率 | "应该能做完"、"半小时就好" |
| 损失厌恶 | 对损失的敏感度高于收益 | "万一失败了怎么办"、"不想放弃" |
| 基本归因错误 | 失败归因外部，成功归因内部 | "运气不好"、"对手太强" |
| 事后合理化 | 用事后理由解释当时决策 | "当时只能那样做"、"回头看是对的" |
| 确认偏误 | 只收集支持自己观点的信息 | "你看，XXX也这么说" |
| 现状偏差 | 维持现状而不愿改变 | "算了，就这样吧" |
| 情绪推理 | 用情绪状态代替理性分析 | "我就是觉得不对" |

## 使用规则

- 偏误触发次数≥3时，Coach Agent 在干预中直接点出偏误名称
- 偏误30天未触发，标记 `[改善中]`
- 偏误频率上升，标记 `[恶化]`
