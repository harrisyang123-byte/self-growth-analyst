# Signal Depth Gate — 信号厚度判定引擎

## 引擎类型
L1 常驻引擎 — 每次碎碎念必加载，约200 tokens。

## 触发时机
linguistic_analyzer 输出后立即执行，先于 auto_insight_generator。

---

## 信号厚度评分（0-10）

| 维度 | 权重 | 评分标准 |
|------|:--:|------|
| 具体行为 | 3 | "我做了X"=3分，"有人搞我"=1分，完全无行为=0分 |
| 归因指向 | 2 | "因为X"=2分，"不知道"=0分 |
| 情绪具体 | 2 | "我焦虑，担心OKR完不成"=2分，"烦"=0.5分 |
| 时间锚定 | 2 | "今天下午"=2分，无时间=0分 |
| 涉及维度 | 1 | 提到具体能力维度=1分，未提及=0分 |

总分 = 各项得分之和，范围 0-10。

---

## 缺口类型与追问方向

| 缺口类型 | 触发条件 | 追问方向 |
|---------|---------|---------|
| [行为缺失] | 具体行为 = 0 | 「你今天具体做了什么？」 |
| [归因缺失] | 归因指向 = 0 | 「你觉得是什么原因造成的？」 |
| [情绪模糊] | 情绪具体 < 1 | 「你说的XX，具体是哪种感受？焦虑/无力/愤怒？」 |
| [时间缺失] | 时间锚定 = 0 | 「这是什么时候的事？」 |
| [多维度缺失] | 多个=0 | 只追问得分最高的那个缺口 |

---

## 锚定追问规则

追问必须包含以下至少一项：
1. retrieval_index 中频率 ≥2 的模式引用
2. active_conflicts 中的相关矛盾
3. pending_actions 中状态为 pending 的行动

**禁止空泛追问**：❌「你再多说说」❌「还有什么？」❌「详细说说？」

---

## 追问上限 ≤ 2次

### 第1次追问
- 当评分 < 5 时，生成锚定追问
- 追问方向根据缺口类型确定

### 第2次追问
- 用户补充后重新评分，仍 < 5
- 换一个缺口方向追问

### 2次后仍不足
- 归档 [极薄输入]
- 不触发 Step 5-6 分析
- 输出 NO_REPLY

---

## [极薄输入] 归档格式

```markdown
[极薄输入] 信号厚度评分: N/10
缺口: [行为缺失]/[归因缺失]/[情绪模糊]/[时间缺失]
追问次数: 2
状态: 已归档，未分析
```

---

## 判定流程

1. 对 linguistic_analyzer 输出做信号厚度评分
2. ≥ 5分 → 继续 Step 4（正常流程）
3. < 5分 → 进入缺口探测：
   - 确定缺口类型
   - 生成锚定追问（引用 retrieval_index/active_conflicts/pending_actions）
4. 追问 ≤ 2次
5. 2次后仍 < 5 → 归档 [极薄输入]，NO_REPLY
